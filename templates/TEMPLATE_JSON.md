## 4. Schema / field reference

> Document every key. For nested objects, use dot notation.

### Root fields

| Key | Type | Required | Default | Description |
|-----|------|----------|---------|-------------|
| `version` | `string` | ✅ | — | Schema version (`"1.0.0"`) |
| `environment` | `string` | ✅ | `"development"` | `"development"` \| `"staging"` \| `"production"` |
| `debug` | `boolean` | ❌ | `false` | Enables verbose logging |

### `server`

| Key | Type | Required | Default | Description |
|-----|------|----------|---------|-------------|
| `server.host` | `string` | ✅ | `"localhost"` | Hostname to bind |
| `server.port` | `number` | ✅ | `3000` | Port to listen on |
| `server.timeout` | `number` | ❌ | `30000` | Request timeout in ms |

### `database`

| Key | Type | Required | Default | Description |
|-----|------|----------|---------|-------------|
| `database.url` | `string` | ✅ | — | Connection string — **do not commit real values** |
| `database.pool.min` | `number` | ❌ | `2` | Minimum connection pool size |
| `database.pool.max` | `number` | ❌ | `10` | Maximum connection pool size |

### `features` (feature flags)

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| `features.newDashboard` | `boolean` | `false` | Enables redesigned dashboard |
| `features.betaApi` | `boolean` | `false` | Enables v2 API endpoints |

## 5. Full annotated example

```jsonc
{
  "version": "1.0.0",
  "environment": "development",    // "development" | "staging" | "production"
  "debug": true,                   // false in production

  "server": {
    "host": "localhost",
    "port": 3000,
    "timeout": 30000               // ms — increase for slow upstream APIs
  },

  "database": {
    "url": "postgres://user:pass@localhost:5432/mydb", // ← override via env var in prod
    "pool": {
      "min": 2,
      "max": 10
    }
  },

  "features": {
    "newDashboard": false,         // enable per-environment in CI
    "betaApi": false
  }
}
```

## 8. Security notes

> Fields that must NEVER be committed with real values.

| Key | Risk | How to handle |
|-----|------|---------------|
| `database.url` | Exposes DB credentials | Use env var `DATABASE_URL` |
| `apiKey` | Exposes third-party access | Use env var `API_KEY` |

> ℹ️ If this file requires secrets, commit a `[filename].example.json` with placeholder values and gitignore the real one.
